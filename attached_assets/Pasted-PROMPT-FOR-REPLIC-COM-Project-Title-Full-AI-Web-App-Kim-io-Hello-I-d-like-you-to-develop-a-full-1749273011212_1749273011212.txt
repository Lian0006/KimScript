PROMPT FOR REPLIC.COM
Project Title: Full AI Web App – KimScript

Hello! I'd like you to develop a fully functional web app called KimScript — a free, easy-to-use platform that uses AI to analyze viral social media videos (just by pasting a video URL), transcribe them, and generate customized scripts for brands or products based on that analysis.

🎯 GOAL OF THE PROJECT:
To create a smart, fast, and intuitive app that lets users paste the URL of any social media video (TikTok, Instagram Reels, or YouTube Shorts), and the AI will:

⚙️ CORE FEATURES (AI logic and UX):
Automatic Video Transcription

Extract the video’s audio from the pasted URL.

Use a model like OpenAI Whisper or similar to generate a clear, punctuated transcription.

Video Content Analysis (GPT-4o or equivalent):
The AI should identify and extract:

The hook or attention-grabber.

Storytelling structure (beginning, middle, end).

The CTA (Call to Action).

Key phrases, keywords, and viral “trigger” words.

Emotional tone and engagement strategies.

A short strategic breakdown of why this video works (viral mechanics).

Script Generator Adapted to User’s Brand/Product

Users will input their product, brand, niche, or audience.

Based on the analyzed video, the AI will generate a custom script aligned with the brand’s tone and audience.

The script should include:

New proposed hook.

Narrative development.

CTA suggestion.

Emotions to evoke.

Optional: visual suggestions, tone of voice.

Content History (Script Archive)

Every script generated by a user should be stored in a personal content history.

Features of the history module:

Display in chronological order.

Show original transcription.

Show full analysis + AI-generated script.

Allow copying, editing, duplicating, and deleting.

(Optional: export to PDF or Google Docs with one click).

UI / UX Design Requirements

Modern, minimal, and powerful interface.

Use a color palette of Electric Blue (#00CFFF) and Deep Violet (#7A00FF).

Homepage designed as a high-conversion landing page.

Clean typography, animations (e.g., Framer Motion), and responsive layout.

Form fields:

Paste video URL.

Enter product/brand/audience.

Display result on the same page with collapsible/expandable sections.

Expert-Trained AI Tone

The AI must be prompted and/or fine-tuned to analyze like a marketing expert, skilled in storytelling, short-form content, and viral video psychology.

Optional: Let users choose tone style (emotional, educational, disruptive, funny, etc.)

🔐 TECH STACK SUGGESTIONS:
Frontend: React + Tailwind CSS + Framer Motion

Backend: Node.js + Express

Database: Supabase, Firebase, or PostgreSQL for content history

Auth: Email-based user accounts (or as you recommend)

AI Services: OpenAI GPT-4o + Whisper API

Hosting: Vercel, Netlify, or Render

💡 INSPIRATION / REFERENCES
Think Opus Clip, Veed.io, or Copy.ai, but focused on analyzing short-form video content and auto-generating tailored marketing scripts.
